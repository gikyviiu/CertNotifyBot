# Описание
Система для централизованного учёта, управления и своевременного оповещения о сроках действия сертификатов электронной подписи (ЭП). Состоит из Telegram-бота и веб-панели.

## Файлы
`cert_notifier_bot.py`: основной файл Telegram-бота

`notify_cert_expiration.py` : скрипт автоматического уведомления

`config.py`: файл конфигурации проекта

`requirements.txt` : файл зависимостей проекта

## Функционал бота

| Кнопка | Описание |
|:--------:|:----------:|
| 🔐 Мой статус | Проверка всех сертификатов пользователя |
| 📧 Экспорт в Excel | Генерация и скачивание персонального отчёта по сертификатам в формате `.xlsx` |
| 📞 Поддержка | Вывод контактных данных технической поддержки |
| ⚙️ Админ-панель | Получение учётных данных для входа в веб-интерфейс (доступно администраторам) |
| 📊 Статистика | Сводная информация по организации: всего сертификатов, активные, просроченные (доступно администраторам) |
| 📢 Рассылка в канал | Отправка уведомлений всем пользователям о важных изменениях или напоминаний о сроках действия ЭП (доступно администраторам) |
