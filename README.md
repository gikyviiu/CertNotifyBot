# CertNotifyBot

## Описание
Система для централизованного учёта, управления и своевременного оповещения о сроках действия сертификатов электронной подписи (ЭП). Состоит из Telegram-бота и веб-панели.

- [Репозиторий Telegram-бота](https://github.com/gikyviiu/CertNotifyBot)
- [Репозиторий веб-панели](https://github.com/gikyviiu/CertWebApp)

## База данных
В данном проекте код написан под локальную БД (использовалась среда MySQL Workbench). Добавлены файлы с моей созданной БД для тестов:
1. Файлы скрипта и модели/EER Dia для создания пустой БД
- `testdbscript.sql`
- `testdbmodel.mwb`
2. Файл для экспорта полной БД с тестовыми данными в ней
- `testdbfulldata.sql`

## Функционал бота
| Кнопка | Описание |
|--------|----------|
| 🔐 Мой статус | Проверка всех сертификатов пользователя |
| 📧 Экспорт в Excel | Генерация и скачивание персонального отчёта по сертификатам в формате `.xlsx` |
| 📞 Поддержка | Вывод контактных данных технической поддержки |
| ⚙️ Админ-панель | Получение учётных данных для входа в веб-интерфейс (доступно администраторам) |
| 📊 Статистика | Сводная информация по организации: всего сертификатов, активные, просроченные (доступно администраторам) |
| 📢 Рассылка в канал | Отправка уведомлений всем пользователям о важных изменениях или напоминаний о сроках действия ЭП (доступно администраторам) |

---

## Скрипт авто-уведомлений
- Проверка сроков действия сертификатов в БД
- Выявление сертификатов, истекающих в ближайшие 7 дней
- Отправка предупреждений пользователям в ЛС, а также в отдельный канал через Telegram-бота
- Логирование просроченных сертификатов
- Может запускаться по расписанию (cron/task scheduler)

## Настройка конфигурации
`config.py`
```
# Telegram
BOT_TOKEN = " ... "  #Токен вашего Telegram-бота
CHANNEL_ID = " ... "  #ID Telegram-канала для отправки массовых уведомлений

# Database
DB_HOST = " ... "  # Адрес сервера, где расположена база данных
DB_USER = " ... "  # Имя пользователя (логин) для доступа к БД
DB_PASSWORD = " ... "  # Пароль для аутентификации пользователя в БД
DB_NAME = " ... "  # Имя самой базы данных (схемы)

# WepApp
# Логин и пароль для доступа к веб-панели(хранятся в БД)
PANEL_LOGIN = " ... "
PANEL_PASSWORD = " ... "
```
